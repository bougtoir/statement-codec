# Statement Codec — reference implementation

Verifiable attributed statements: signed original statements, signed span
quotations with positional context constraints, a bitemporal model separating
statement validity from commitment horizon, consent manifests, and a
hash-chained audit log with witness-cosigned checkpoints.

This is a **research reference implementation** accompanying an experience
report. All evaluation data are **synthetic**; nothing here measures or
claims effects on human behaviour, journalism, or public discourse.

## Requirements
- Python ≥ 3.10
- `cryptography >= 3.4` (see `requirements.txt`)

## Install
```
pip install -r requirements.txt
```

## Minimal example
```python
from codec import (gen_key, key_id, make_statement, make_context_constraint,
                   make_quotation, verify_quotation, make_consent_manifest)

NOW = "2026-01-01T00:00:00Z"
speaker, recorder = gen_key(), gen_key()     # TEST KEYS ONLY — never commit real keys
sk, rk = key_id(speaker.public_key()), key_id(recorder.public_key())
text = "I will support the plan if the revenue forecast holds, though I doubt it will."

man = make_consent_manifest([speaker, recorder], "demo",
      parties=[{"keyid": sk, "role": "speaker",  "disclosure": "real_name"},
               {"keyid": rk, "role": "recorder", "disclosure": "real_name"}],
      terms={"recording": True, "direct_quote": True},
      effective_at="2025-12-01T00:00:00Z")
st  = make_statement(speaker, "demo", text, NOW, NOW, NOW, [], "on-record",
                     valid_from="2026-01-01T00:00:00Z", valid_until="2026-12-31T00:00:00Z")
cc  = make_context_constraint(speaker, st["body"]["statement_id"],
                              [[22, 53]], "conditional", "mandatory clause", "speaker")
pkg = {"objects": [man, st, cc],
       "pubs": {sk: speaker.public_key(), rk: recorder.public_key()},
       "revocations": {}}
q   = make_quotation(recorder, st, [[0, 21]], "I will support the plan", "demo")
r   = verify_quotation(pkg, q, t_event="2026-06-01T00:00:00Z")
# r["label"] == "CONTEXT_FLAG"; r["context"]["status"] == "MISSING"
```

See `codec.py` docstrings for the full API: `statement_validity`,
`check_use`, `AuditLog`, `checkpoint`, `detect_fork`.

> Keys generated by `gen_key()` are for testing/reproduction only. Never
> commit real private keys or credentials; this repository must never
> contain production secrets.

## Scope and limits (non-goals)
- Syntactic checks only: paraphrase-level misframing is out of scope.
- Context constraints are conjunctive; OR/NOT logic is not implemented.
- Nested quotation chains (quote-of-quote) are not supported (documented counterexample).
- Permission verdicts are agreement states, not legal findings.
- Permission verdicts and labels are evidence for humans; the system is a
  labelling layer, not an enforcement or adjudication layer.

## Ethics & privacy
- Corpus data are generated by documented rules with a fixed seed; there are
  no real statements, participants, or personal data.
- Do not feed real people's statements into the shipped generators and present
  the outputs as if they were measurements of real discourse.
